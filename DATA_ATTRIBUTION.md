# Data attribution and release scope

Source: **Olist — Brazilian E-Commerce Public Dataset by Olist**, published on [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce). The publisher's dataset page was checked on 27 November 2026 and lists **CC BY-NC-SA 4.0**. See the [license deed](https://creativecommons.org/licenses/by-nc-sa/4.0/).

This project transforms the supplied snapshot into analytical marts, aggregates, Power BI imports and screenshots. Changes include calendar-date delivery classification, per-order review averaging, seller–order deduplication, category translation and financial reconciliation. Olist does not endorse this portfolio or its proposed pilot.

The original Kaggle download version was not supplied. Local source file hashes, sizes and row counts are recorded in [the reproducibility manifest](evidence/reproducibility_manifest.json). This identifies the analyzed copy without claiming that it is a verified byte-for-byte download of a particular Kaggle version.

Raw CSVs remain outside version control. The PBIX embeds imported data, including pseudonymous order/customer/seller identifiers. The owner authorized this public portfolio handoff. No live personal-data processing or customer intervention was performed. Any subsequent distribution should preserve attribution, indicate transformations and observe the source license's noncommercial and share-alike terms. The dataset license does not automatically license the project's original code or the owner's dashboard template.
